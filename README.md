# The Walking Dead

*Created by Frank Darabont*, **The Walking Dead** is a post-apocalyptic horror drama based on the comic book series by Robert Kirkman.

> "We are the walking dead!"

## Key Themes
1. Survival in a collapsed society
2. Moral dilemmas and human nature under extreme pressure
3. The conflict between different survivor factions

## Iconic Characters
- Andrew Lincoln as **Rick Grimes**
- Norman Reedus as **Daryl Dixon**
- Melissa McBride as **Carol Peletier**
- Lauren Cohan as **Maggie Greene**
